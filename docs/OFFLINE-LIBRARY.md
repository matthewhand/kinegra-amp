# Offline library

The distribution starts with no music. Open **Offline Library → Import from USB / Internal Storage** and choose MP3/Ogg files through Android's picker. Import creates app-owned copies; it never changes the originals or the active Music Assistant source/queue. Each operation is bounded to 32 files and each file to 64 MiB.

The browser uses 25-row pages. Highlighting or opening the library is silent. Select a row, then choose **Play** or **Add to Queue**. **Delete Copy** requires confirmation, removes only the app copy and leaves USB/source files unchanged. Import can be cancelled; failed or partial operations show their status. Missing/unsupported files remain unavailable rather than being played as another track.

The first four catalog slots are reserved for compatibility with older installations. The music-free app does not load or restore bundled songs/covers. Existing imported tracks retain indices from four onward, along with their favorites and local queue identities. An unavailable old selected mix falls back to All Tracks without erasing the saved file at startup. Explicit queue playback skips unavailable entries and preserves remaining imported-track order.

Music Assistant streaming remains separate from this library. Buffered audio is temporary playback data, not an offline song download. User-supplied music retains its own terms.
