# ShieldAmp 1.0.2

*Historical release notes from before the Kinegra Amp rebrand.*

The web remote starts with Tracks, which works for libraries whose songs have no album records. Playback reconnects now wait for a fresh verified own-output route before reading or changing the queue; only read-only discovery is retried. An explicitly empty queue is shown as empty without requesting an invalid upcoming offset.

Includes the 1.0.1 connection feedback, searchable Music Assistant browsing, Play/Add to Queue/Queue Page and upcoming-queue view. Original package/signing identity and app data are retained. Version code 78. Production defaults off, development on; existing user choices remain remembered. [Remote usage/API](WEB-REMOTE.md).
