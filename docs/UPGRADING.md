# Updating Kinegra Amp

Install the signed update over your existing installation with `adb install -r KinegraAmp-1.0.15.apk`. Keep the same signing identity and app data to retain settings, imported music and pairing. Do not uninstall or clear data to apply an update.

The Android package is `org.local.tegramilkdrop`. Build and signing instructions are in [BUILDING.md](BUILDING.md). Keep credentials, device-generated keys and user files outside source and release archives.
