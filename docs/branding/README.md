# Kinegra Amp artwork

`kinegra-amp-banner.png` is original illustrative artwork created with AI assistance. The launcher banner and splash are deterministic size conversions; run `python3 packaging/prepare_branding.py` to reproduce them. The square icons use original headphone-dancer artwork.

Original artwork and hero media use [MIT](../../LICENSE). The banner is an illustration rather than an application screenshot. No third-party album cover or artist likeness is included.
